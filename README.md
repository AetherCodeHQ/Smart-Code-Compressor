# Smart-Code-Compressor

AI-optimized code compression

## Features

- Easy-to-use CLI interface
- Fast and efficient processing
- Cross-platform support

## Installation

```bash
git clone https://github.com/Qyroxen/Smart-Code-Compressor.git
cd Smart-Code-Compressor
go build -o smart-code-compressor .
```

## Usage

```bash
.smart-code-compressor .
.smart-code-compressor --path ./src
```
